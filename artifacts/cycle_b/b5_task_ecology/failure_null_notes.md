# B5 failure and null-result notes

- Aggregate tasks remain excluded because competence was not established.
- A one-seed validation pilot excluded argmax-position (0.567) and argmin-position (0.583).
- A five-seed mixed-identifiability pilot left task validation means at 0.813--0.917 and no competence-matched pair; B5 revision 3 therefore uses high-identifiability wording only. Pilot frozen-test measurements are not retained or used in claims.
- Only preregistered competence-matched pairs enter utility claims.
- Goal maps compare relative token bins because natural-language instructions have unequal lengths.
- Nearest-centroid goal probes are validation-fit linear discriminants, not causal controls.
